### 🏗️ System Design — SSR vs CSR vs SSG

**CSR — Client-Side Rendering**
The browser runs JavaScript to render much of the page and fetch data. Useful for interactive dashboards and app-like experiences.

**SSR — Server-Side Rendering**
The server generates HTML for a request. Useful when the initial response needs request-specific data or server-rendered content.

**SSG — Static Site Generation**
Pages are generated ahead of time and served as static content. Useful for documentation, marketing pages, and other mostly static content.
