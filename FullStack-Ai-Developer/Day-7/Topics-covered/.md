## 📅 Day 7 — TypeScript Fundamentals

### 🟦 TypeScript — Core Learning Goals
**TypeScript checklist -**
-   Understand TypeScript and JavaScript differences
-   Set up TypeScript and understand `tsconfig.json`
-   Learn type annotations and type inference
-   Master primitive types, arrays, tuples, and objects
-   Type functions, parameters, and return values
-   Understand `any`, `unknown`, `void`, `never`, `null`, and `undefined`
-   Learn interfaces vs type aliases
-   Practice optional and readonly properties
-   Understand union and intersection types
-   Master type narrowing and custom type guards
-   Learn generics for reusable, type-safe code
-   Understand utility types: `Partial`, `Pick`, `Omit`, `Readonly`, `Record`

### 🤖 AI — Type-safe AI responses
-   Understand basic LLM SDK request and response structures
-   Define TypeScript interfaces for AI responses
-   Use `Promise<T>` to type asynchronous AI functions
-   Handle API errors and optional fields
-   Understand compile-time types vs runtime validation
-   Validate AI-generated JSON before using it

**Practical goal:** Create a typed AI response object with `answer` and `confidence` fields.

### 🏗️ System Design — API Contracts and OpenAPI
-   Understand API contracts and why they matter
-   Learn request and response schemas
-   Study HTTP status codes and standardized error responses
-   Understand path parameters, query parameters, and request bodies
-   Learn OpenAPI fundamentals: paths, operations, and schemas
-   Understand how frontend and backend teams keep API types consistent

**Practical goal:** Define a TypeScript type for a user API response and document a sample `GET /users/:id` endpoint.

### 🛠️ Night Project — Convert Your Project to TypeScript
-   Configure TypeScript in an existing project
-   Convert one React component from `.jsx` to `.tsx`
-   Add types to component props, state, and event handlers
-   Type one API request and response
-   Remove unnecessary `any` types
-   Run the project and fix TypeScript errors
-   Run the available tests
