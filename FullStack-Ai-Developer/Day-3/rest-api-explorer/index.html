GET /posts/1

Reads a resource. Safe and idempotent — calling it repeatedly never changes anything on the server.

POST /posts

Creates a new resource. NOT idempotent — calling it twice creates two resources. Expect 201 Created.

PUT /posts/1

Replaces the ENTIRE resource with the body sent. Idempotent — sending it twice leaves the same end state.

PATCH /posts/1

Updates ONLY the fields sent. Everything else on the resource is left untouched.

DELETE /posts/1

Removes the resource. Idempotent — deleting something already gone still ends with "it's gone".
