## 📅 Day 9 — React Hooks

### ⚛️ React — Main Learning Goals

**A. `useState`**
-  Review state and state updates
-  Update objects and arrays immutably
-  Use functional state updates
-  Understand batching and state snapshots

**B. `useEffect`**
-  Understand side effects and effect timing
-  Use dependencies correctly
-  Implement cleanup functions
-  Fetch data and handle loading/error states
-  Prevent stale updates and race conditions

**C. `useRef`**
-  Store mutable values without triggering re-renders
-  Access DOM elements
-  Manage focus and scrolling
-  Understand `useRef` vs `useState`

**D. `useMemo`**
-  Understand memoization
-  Cache expensive calculation results
-  Use dependencies correctly
-  Know when memoization is unnecessary

**E. `useCallback`**
-  Memoize function references
-  Understand function identity
-  Use callbacks with memoized child components
-  Know when `useCallback` helps

**F. Custom Hooks**
-  Understand why custom Hooks are useful
-  Follow the Rules of Hooks
-  Extract reusable stateful logic
-  Return data, loading, error and action values
-  Separate data logic from UI components

### 🤖 AI — Chat Streaming UX and Optimistic UI
-  Understand how a chat interface manages conversation state
-  Display responses progressively as streamed chunks arrive
-  Show loading, streaming, completed and error states
-  Prevent or manage duplicate submissions
-  Understand optimistic UI: update the interface before server confirmation
-  Handle failures with an error message and retry option
-  Prevent outdated responses from overwriting newer conversation state
-  Distinguish temporary optimistic messages from confirmed messages

### 🏗️ System Design — Caching Concepts
-  Understand why applications use caching
-  Learn cache hits and cache misses
-  Understand cache invalidation
-  Compare browser caching with server-side caching
-  Learn HTTP caching headers, including `Cache-Control` and `ETag`
-  Understand stale data and cache expiration
-  Differentiate API data caching from computed-result memoization
-  Understand how caching affects performance and data freshness
