## 📅 Day 8 — React Fundamentals

### ⚛️ React — Main Learning Goals
**React learning checklist — 0/30**

**A. React Setup and JSX**
-  Understand React and why it is used
-  Understand React vs vanilla JavaScript
-  Set up a React project and understand its folder structure
-  Learn JSX syntax, expressions and rules
-  Understand how React renders UI

**B. Components and Composition**
-  Create functional components
-  Understand component composition
-  Break a page into small reusable components
-  Pass data using props
-  Understand parent-to-child data flow
-  Decide where component state should live

**C. State and Events**
-  Understand state vs ordinary variables
-  Learn `useState` fundamentals
-  Handle click events
-  Handle input changes
-  Handle form submissions
-  Understand state updates and re-renders
-  Avoid directly mutating state

**D. Forms and User Input**
-  Build controlled forms
-  Use `value` and `onChange` correctly
-  Handle form submissions
-  Validate required inputs
-  Prevent default browser form submission when appropriate
-  Display validation feedback

**E. Lists and Conditional Rendering**
-  Render lists using `map()`
-  Understand stable and unique keys
-  Know why array indexes can be problematic as keys
-  Use conditional rendering
-  Build loading, empty and error states
-  Understand the basic React render cycle

### 🤖 AI — Chat Interface Patterns
-  Understand the structure of a chat interface
-  Display user messages and assistant messages
-  Show a loading indicator while waiting for an AI response
-  Understand streaming responses and progressive text rendering
-  Display errors when an AI request fails
-  Handle empty prompts
-  Prevent duplicate submissions while a request is in progress
-  Distinguish between loading, streaming, completed and failed states
-  Understand the difference between a simulated response and a real AI API response

**Practical goal:** Build a chat interface in React with simulated responses, loading indicators and error states.

### 🏗️ System Design — Frontend Architecture and Component Boundaries
-  Understand component-based frontend architecture
-  Break a page into reusable components
-  Understand parent-child relationships and props
-  Decide where state should live
-  Understand component composition
-  Separate UI presentation from business logic
-  Organize components, pages and shared utilities
-  Sketch a component tree before implementation
-  Understand when to reuse a component and when to keep it page-specific
