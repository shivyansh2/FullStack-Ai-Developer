## 📅 Day 11 — State Management, Performance & Caching

### ⚛️ React State Management
-  Understand local state vs global state vs server state
-  Learn Redux Toolkit fundamentals and the Redux data flow
-  Learn Zustand stores, actions, and selectors
-  Understand TanStack Query for server-state management
-  Practice when to use Context, Zustand, Redux, or TanStack Query

### ⚡ React Performance
-  Understand unnecessary re-renders
-  Learn `React.memo`, `useMemo`, and `useCallback` trade-offs
-  Use React DevTools Profiler to identify actual bottlenecks
-  Understand stable keys and expensive computations

### 🤖 AI Response Caching
-  Understand why repeated AI requests can be cached
-  Design cache keys using model, prompt, parameters, and context
-  Understand TTL, cache misses, and invalidation
-  Consider user isolation, privacy, and stale responses
-  Understand token and cost awareness

### 🏗️ System Design — Cache-Aside and Redis
-  Learn the cache-aside read/write flow
-  Understand cache hit, miss, TTL, and invalidation
-  Learn what Redis stores and why it is fast
-  Understand cache stampedes and stale data
-  Draw a frontend → API → Redis → database architecture
