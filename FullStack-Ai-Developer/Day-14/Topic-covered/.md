### 🏗️ System Design — Load Balancing and Horizontal Scaling

**Load balancing**
Distributes incoming requests across multiple backend instances to improve availability and handle traffic.

**Horizontal scaling**
Adds more server instances instead of relying on one increasingly powerful server.

**Stateless backend design**
Avoids depending on in-memory session data in a single instance, making it easier to distribute requests across servers.

**Health checks and failure handling**
Help a load balancer avoid sending traffic to unhealthy instances.
