# 🚀 50-Day Full-Stack + AI Challenge
 
> **Learn → Code → Solve → Design → Build → Test → Explain**
 
A public log of my 50-day journey to become a job-ready full-stack engineer with real AI skills. Every day covers one main technology, DSA, an AI concept, system design, a night-time project feature, and interview practice. One flagship project grows across all 50 days.

## ⏰ Daily Schedule
 
| Time | Block | Focus |
|------|-------|-------|
| 08:00 – 08:30 | Revision | Yesterday's notes + 3 interview questions |
| 08:30 – 11:00 | Main Topic | Theory → internals → advanced → live coding |
| 11:30 – 13:00 | Interview | Explain + debug + tricky questions |
| 14:00 – 15:30 | DSA | Listed problems + error log |
| 16:00 – 17:00 | System Design | Architecture + trade-offs + diagram |
| 17:00 – 18:00 | AI | Concept + mini implementation |
| 19:30 – 22:00 | Project | Build today's feature + test + commit |
| 22:00 – 22:30 | Wrap-up | Revision + tomorrow's target |
